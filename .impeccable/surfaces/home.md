# Surface: Quickdraft home

Mode: Operate

THESIS: One-handed draft decisions, not a companion dashboard. The screen refuses the usual stacked-stat-card layout and makes the enemy five + resulting item rail the dominant interaction.

OWN-WORLD: Telegram-native adaptive surfaces, one host accent, thin dividers, 14px corners only where controls need containment, and dense but breathable typography. No decorative gradients, glass, neon, or game-client cosplay.

STORY: Pick or import five enemies, optionally mark game state, and immediately receive one recommended Yunara path plus the decisive reasons and one close alternative. Patch/meta freshness stays visible but subordinate.

FIRST VIEWPORT: A compact freshness line, five enemy slots across a wrapping rail, an inline search field directly below the active slot, then a large build rail occupying the visual center. Game-state controls sit below the path instead of delaying it. Primary action is selecting the next enemy; selection auto-advances.

FORM: Code-led tactical draft rail. Engine seed unavailable in this environment; fallback direction chosen from the product brief for a single-user Operate surface.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
